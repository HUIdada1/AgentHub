# AgentHub —— Agent 中控台

<p align="center">
  <a href="./README.md">简体中文</a> · <a href="./README.en.md">English</a>
</p>

> 把「技能、用量、额度、记忆、提示词」五件事收进一个 Windows 桌面应用。

AgentHub 是本地运行的中控台（Electron + Vue 3 + TypeScript），自身不带模型，只把你散在各家 AI 编程工具里的东西管起来：Skill 重复安装、这个月 token 花在哪儿、订阅额度能不能给别的客户端用、Agent 记不住项目、每次开新会话都要重写同一段提示词。这五件事对应下面五个板块。

提供 **Windows 桌面版**（五个板块全功能，见 [Windows 版下载与安装](#windows-版下载与安装)）。原 **Docker 版**随「反代网关」模块停止维护已一并下线。

| 板块 | 一句话 | 适合谁 |
| --- | --- | --- |
| **技能仓库** | 各工具的 Skill 收进一个中央库，一处维护、一键挂回 | 同时用 Codex / Claude Code / ZCode / Cursor 等多个工具的人 |
| **用量统计** | 汇总 21 个数据源的 token 用量与费用，按天 / 项目 / 模型看趋势 | 想知道这个月到底烧了多少的人 |
| **号池管家** | 把各渠道的账号收进一个号池，集中看余额、管签到、跨设备同步（原「反代网关」已停止维护） | 手里有多渠道订阅额度（Trae / WorkBuddy / 小浣熊 / 魔搭 / ZCode / Qoder / Cline 等 14 个渠道）、想知道余额还剩多少的人 |
| **记忆中枢** | 本地 Markdown 记忆库 + MCP 服务，让 Agent 记住项目和偏好 | 不想每次开新会话都重新交代背景的人 |
| **提示词库** | 把一句话扩写成规范提示词，好用的存起来复用，另有 60 条精选目录 | 反复重写同一段提示词、或不知道该怎么把需求说清楚的人 |

## Windows 版下载与安装

### 安装版

1. 打开 [Releases 页面](https://github.com/HUIdada1/AgentHub/releases/latest)
2. 下载 `AgentHub-Setup-x.y.z.exe`
3. 双击安装。安装过程中可以改安装目录，装完会在桌面和开始菜单创建「AgentHub」快捷方式
4. 启动后程序常驻系统托盘，关窗口不会退出；托盘图标双击可唤回窗口，右键菜单里能暂停同步、看今日用量

### 系统要求

- Windows 10 / 11（x64）
- 不需要预装 Node、浏览器等任何依赖，运行时已打包在内
- 部分能读到数据的工具需要本机登录过对应客户端（如用量统计要读 Codex、Trae 的本地库）

### 数据、更新与备份

- 配置与多数数据存在 `%APPDATA%\AgentHub`，卸载程序不会删除它
- 例外：三个「用户资产」放在用户目录下，方便你直接备份或丢进 Git——技能仓库 `~/.agent_skills`（可用环境变量 `AGENT_SKILLS_HOME` 改）、记忆库 `~/AgentHub/memory`、提示词库 `~/AgentHub/prompts`
- 自动更新：默认**每小时**检查一次 GitHub Releases，检测到新版本会在侧栏设置齿轮和「设置 · 通用」的更新按钮上冒红点；自动检查可在「设置 · 通用」关闭
- 左下角「设置」= 全局项（通用 / WebDAV 同步 / 同步时间 / 数据与备份）；每个板块右上角还有一个「配置」按钮，管的是这个板块自己的设置

## 板块一：技能仓库

### 它解决什么问题

同一个 Skill 你在 Codex、Claude Code、ZCode、Cursor 里各装了一份，改一处忘三处。技能仓库把所有工具的 Skill 目录收进一个中央仓库，再挂载回各工具：以后只在中央库维护，一处更新，处处生效。

### 页面构成

| 页面 | 作用 |
| --- | --- |
| 仪表盘 | 中央库与各工具连接状态总览：收了多少技能、挂载是否健康、有没有孤儿目录 |
| 中央技能库 | 技能列表与详情，逐条查看/收纳/挂载，挂载失效时可一键修复 |
| 去重与冲突 | 同一技能在不同工具里内容不一致时列出差异，人工裁决保留哪份；工具目录里的链接指向别处时，决定链接该指向谁 |
| 同步中心 | 扫描预览 → 确认执行 → 查看报告，一次把「收什么、挂什么、有什么要裁决」讲清楚 |
| WebDAV 同步 | 中央仓库跨设备同步（服务器地址在「设置 · WebDAV 同步」里配） |

### 怎么用

1. 打开「技能仓库 · 仪表盘」，确认工具列表里检测到了你的工具（ZCode / Codex / Claude Code / Antigravity / 通用 `~/.agents` 为内置，其他工具会按本机目录自动建议添加）
2. 进入「同步中心」，先点扫描看看这次会收哪些技能、往哪些工具挂——预览不写任何文件，看清楚再执行
3. 点执行。技能会以软链接（junction）的方式从中央仓库挂回各工具，几乎不占额外空间
4. 日常在某处新增/修改了技能，回「同步中心」再跑一次即可；出现冲突会进入「去重与冲突」页面等你裁决
5. 多台电脑：在「设置 · WebDAV 同步」填好服务器，然后在「WebDAV 同步」页跑一次，中央仓库就同步过去了

## 板块二：用量统计

### 它解决什么问题

用量散在各家工具自己的本地库里，没人告诉你这个月一共花了多少。用量统计直接读**本机客户端的数据文件**，把 21 个数据源归一到同一套口径，做汇总、趋势、费用和跨设备对比。

### 支持的数据源（21 个）

ZCode、商汤小浣熊、Xiaomi MiMo、Codex、DeepSeek Harness、WorkBuddy、WorkBuddy AI、Reasonix、CodeBuddy、Qoder、Qoder CN、Antigravity、Antigravity IDE、Antigravity 老数据恢复、Trae、Trae CN、TRAE SOLO、TRAE SOLO CN、OpenSquilla、Grok、AutoClaw。

在「配置 · 用量统计」里可以逐个开关、指定自定义数据目录——没装过的源自动跳过，不会报错。

### 页面构成

| 页面 | 作用 |
| --- | --- |
| 总览 | 核心指标卡 + 全年热力图 + 用量趋势（当天可按小时看）+ 各电脑用量构成 |
| 用量明细 | 按来源/模型/项目筛选，逐条记录，可分页、可导出 CSV |
| 费用 | 按模型价格折算费用；需要先在「计费规则」里配好价格 |
| 计费规则 | 模型价格表、远程价格源、模型别名归并（变体模型名按目标价格计费） |
| 同步日志 | 每次同步的时间、窗口、条数、结果，出问题先看这里 |

### 同步节奏

- 本机统计：**每 30 分钟**自动入库一次（固定，不设开关）
- 跨设备同步：在「设置 · 同步时间」里配置，支持「每小时」或「每天定时」两种自动节奏，也可以随时手动触发
- 没有配置 WebDAV 也能正常用：会自动进入本地模式，只统计本机数据

## 板块三：号池管家

> 原「反代网关」模块已停止维护，改造为「号池管家」：保留号池账号、余额、签到与跨设备同步，**不再提供 API 转发能力**。维护策略调整说明见本节末尾。

### 它解决什么问题

订阅额度散在十几个客户端里：这个号还剩多少、哪天到期、今天签到没有、换台电脑还得重新登一遍。号池管家把这些账号收进一个本地号池，集中看余额、管签到、跨设备同步，凭据经 DPAPI 加密落盘。

### 页面构成

| 页面 | 作用 |
| --- | --- |
| 总览 | 各渠道余额聚合、账号可用性、即将到期提醒、最近动态 |
| 号池 | 按渠道管理账号：状态、余额、套餐到期、策略、添加账号、一键签到、切到 IDE |
| 积分日历 | 把所有渠道所有账号的积分包拉平，按到期升序统一呈现；默认只列有余额的包 |
| 号池同步 | 多台电脑共享号池：账号与凭据打包经 WebDAV 同步，可选只同步某一个渠道 |
| 日志 | 号池操作日志：按时间 / 等级 / 类型筛选，可导出 Excel |

### 支持的渠道

| 渠道 | 对应订阅 | 登录形态 | 签到 |
| --- | --- | --- | --- |
| **Trae SOLO CN** | Trae SOLO 国内版 | 官方授权页 + 本机回环回调 | 每日签到 |
| **WorkBuddy CN** | WorkBuddy 国内版 | 官方登录页 + 本机轮询 | 每日签到 |

### 怎么用

#### 往号池里加账号

进入「号池管家 · 号池」，先在顶部选中渠道，再点**添加账号**。每个渠道都支持四种添加方式，挑一种就行：

1. **OAuth 登录**（最推荐）——跳转官方授权页登录，登录完成后自动入池，全程不用手工填任何 token：
   - Trae SOLO CN：授权后会回调本机回环地址；万一浏览器停在回调页没自动跳回，把地址栏内容整段粘到输入框兜底
   - WorkBuddy 两个版本：登录完本机自动轮询结果，无需任何粘贴
   - 商汤小浣熊：授权窗在 AgentHub 应用内弹出，授权码由应用直接截获；被拦截时可粘贴 `office-raccoon://auth/callback?code=…` 兜底
   - ZCode：跳 Z.ai 授权页，登录后自动入池；随后后台会用几十秒初始化套餐
   - Qoder 两个版本：跳官方登录页（qoder.cn / qoder.com）完成登录，本机每秒轮询直接取回设备凭据对，**无需本机安装客户端、也不用粘贴回调**
   - LobsterAI（有道龙虾）：跳官方登录页（lobsterai.youdao.com）登录，回调本机回环地址自动入池，**无需安装客户端**
   - Cline 双渠道：跳 WorkOS 设备授权页（已带用户码，点一次确认即可）完成登录，本机自动轮询入池，**无需安装客户端、不占用本地回调端口**
   - 每次登录对应一个账号，想加几个号就重复几次
2. **从本机软件导入** —— 直接扫描本机已登录客户端的凭据，零请求入池，最省事（Qoder 走的也是这条）
3. **从 JSON / ZIP 文件** —— 批量导入别人给你的账号文件
4. **粘贴 JSON** —— 手动粘贴单条或一组凭据

账号加进来后，号池列表里能看到它的余额、套餐到期时间和状态（online / cooling / exhausted / relogin / disabled）。想主动养护账号，点该渠道的**一键签到**（或领加油包，Qoder 是「领 Credits」）；也可以打开定时自动签到，每天到点自动跑全渠道。

#### 看余额与到期

「总览」页按渠道列出余额、可用账号数与最早到期时间；「积分日历」把逐包明细按到期升序铺开，快过期的排在最前。额度刷新周期与「即将到期」预警阈值都在「配置 · 号池管家」里改，保存即生效。

#### 切到本机 IDE（可选）

号池里每个账号都有一个「切到 IDE」按钮：把该账号写成本机客户端的当前登录态，适合「号池里的号想直接在本机客户端里用」。

- 支持 WorkBuddy 双区、商汤小浣熊、ZCode。**Trae 不支持**——它的登录态是绑定设备密钥的加密信封，构造不出合法文件，程序会直接说明原因，不会硬写
- 点击后会弹确认框，确认即自动：关闭客户端 → 备份原登录态 → 写入 → 重新打开客户端
- 写入前后有多道校验（防并发回写、写后回读校验失败自动回滚）；ZCode 采用合并式写回，不会动你的远程连接地址；小浣熊会保留账号专属设备指纹，避免跨号串号导致旧号被吊销

### 多台电脑共享号池

「号池同步」页把账号与凭据打包（用统一 WebDAV 密码 AES-256-GCM 加密）传到 WebDAV，另一台电脑拉下来即可共用同一批号。可以选择同步全部渠道，也可以只同步某一个渠道；进度按阶段展示，中途可看细节。

### 与原「反代网关」的差异

**已下线**（代码归档、不再维护）：API 转发服务（OpenAI / Anthropic / Responses 三条协议面）、API Keys、模型目录、网关用量统计、自定义提供商、CC Switch 生态接入、网络代理（出口池）、Docker 版与远程实例、规则热加载。

**保留**：号池账号管理、余额查询、积分签到、号池同步、操作日志、IDE 切号。

### 维护策略调整说明

> 关于「反代网关」模块维护策略调整的说明
>
> 经评估，本项目「反代网关」模块将转入停止维护状态，后期修改为「号池管家」模块。
>
> 维护范围：不再进行该模块的功能开发与代码更新，不再跟进各渠道上游的协议调整与风控策略变化，亦不再受理相关新增 issue 与 PR。
>
> 调整原因：本项目为个人自用工具，不具备长期投入协议适配与风控对抗的持续维护能力；受上游策略更新频率影响，反代通道的稳定性与可用周期已不具备可控性，继续投入适配工作的实际价值有限。
>
> 仓库现状：仓库保持现有可用状态，已合入的修复内容不作回退。
>
> 风险提示：敬请使用者自行评估使用风险。受上游策略影响，该功能存在随时不可用的可能；因使用非官方客户端而产生的账号风控、限制或封禁等后果，由使用者自行承担。

## 板块四：记忆中枢

### 它解决什么问题

Agent 每次开新会话都不记得你的项目背景、技术决策和踩过的坑。记忆中枢在本地维护一个 **Markdown 记忆库**，把会话里值得长期保留的事实沉淀下来，再通过 **MCP 服务**给各个 Agent 读写——你的记忆始终是本地一堆可读、可 diff 的 md 文件。

默认仓库在 `~/AgentHub/memory`：`projects/<项目>/l1/<agent>/<日期>.md` 存原始事实，`projects/<项目>/l2/...` 存蒸馏出的项目汇总、决策与知识。

### 页面构成

| 页面 | 作用 |
| --- | --- |
| 仪表盘 | 记忆总量、增长趋势、各项目与 Agent 的分布 |
| 记忆浏览 | 列表 / 热力图 / 待确认 / 回收站四个视图；三类待人工裁决的条目在「待确认」里处理 |
| 项目归档 | 按项目看汇总与归类溯源，项目可重命名、合并到其他项目 |
| 深层画像 | 从长期记录里蒸馏出的偏好与人格画像 |
| Agent 接入 | 一键给各 Agent 注入 MCP 与指令块，并做三级校验 |
| 检索与索引 | 全文检索（中文 bigram 分词 + 同义词扩展），索引状态与自愈 |
| 自动化 | 九个后台任务的开关、节奏、立即执行与运行历史 |
| 导入与去重 | 从各工具的历史会话导入记忆，重复内容合并 |
| WebDAV同步 | 记忆库跨设备同步 |

### 怎么用

1. **接入 Agent**：进入「Agent 接入」，找到你要用的 Agent（内置 ZCode、Codex CLI、WorkBuddy、Claude Code、DeepSeek Harness、Trae Solo、Cursor、通用 `~/.agents`），点一键注入。它会做两件事：往 Agent 配置里加一条 MCP 启动项，往它的指令文件（`AGENTS.md` / `CLAUDE.md` 等）写一段受控块——都在写前自动备份，卸载时只删自己的部分
2. **验证**：卡片上的三级校验会依次确认「配置条目在不在 → 桥能不能真的拉起并列出工具 → 这个 Agent 有没有真的调用过」。只有第三级出现心跳，才说明它确实在用
3. **导入历史**：进入「导入与去重」，把已有会话历史导进来做底料（支持 Codex、ZCode、WorkBuddy 等来源的会话库），导入前可以先跑干跑预览
4. **开自动化**：进入「自动化」按需打开任务。九个任务分两类：
   - 本地算法类：项目归类建议、索引自愈扫描（不耗 token）
   - 需要模型类：抽取结构化信息、生成摘要、自动打标签、失效判定、L2 蒸馏、去重合并、人格/偏好画像
5. **给记忆任务配模型**：在记忆中枢的配置页选择模型来源——填自己的 OpenAI 兼容 API（Key 存本机、界面只显掩码），并配置失败时的降级链

### 待确认收件箱

自动化跑完后，有三类结论不会直接生效，而是排队等你确认：**事实失效判定**（新事实是否覆盖旧事实）、**项目归类建议**、**去重合并建议**。它们收在「记忆浏览 → 待确认」里，逐条采用或驳回；每条都带推荐建议，也可以按推荐一键全部确认。

## 板块五：提示词库

### 它解决什么问题

同一段提示词，你在每个新会话里都要重写一遍；想说「帮我写个周报」，又不知道该怎么补才够清楚。提示词库把这件事拆成三步：**让模型替你扩写**（优化提示词）、**好用的存起来复用**（个人库）、**直接拿现成的**（线上目录）。

### 页面构成

| 页面 | 作用 |
| --- | --- |
| 优化提示词 | 上框原文、下框结果；6 套内置风格 + 「补充要求」+ 角度引导；边生成边显示 |
| 优化历史 | 最近 50 次优化的原文 / 结果 / 耗时 / 用量，可一键回填重跑 |
| 个人提示词库 | 分类树、标签、收藏、版本历史、回收站、导入导出、全文搜索 |
| 线上提示词库 | 内置 60 条精选 + 10 套模板，可检查更新，也可导入自己的数据集 |
| WebDAV 同步 | 提示词库跨设备同步，冲突可逐条裁决 |

### 6 套内置优化风格

| 风格 | 什么时候用 |
| --- | --- |
| 通用增强 | 默认。补上下文、明约束、结构化，保持语言一致 |
| **多角度补全** | **原话很短、信息量不足**时用（如「帮我写个周报」）。先按 9 个角度扫描缺口，再用合理假设补齐，最后按规范骨架输出 |
| 更简洁 | 只做减法：删冗余、去重复、压缩表达，不新增要求 |
| 更结构化 | 强制分层：目标 / 输入 / 约束 / 输出格式 / 验收标准 |
| 补全约束 | 重点补边界条件、禁止项与可判定的验收标准 |
| 面向编码任务 | 目标场景预设为编码助手：补技术上下文与可验收的完成条件 |

「多角度补全」的两个关键设计：

- **不编事实**：人名、机构、数字、日期、金额、型号一律留成 `{{变量}}`，不替用户瞎猜
- **假设看得见**：模型替你做的假设（最多 3 条）单独列在结果下方，每条都写「若不成立会变成什么样」；选中正文里的对应文字点「→ 变量」，就能把它变成可填写的变量

### 三个值得一试的细节

1. **补充要求**：想加一句「面向不懂技术的老板」，写在原文框下面的「补充要求」里就行，不用改原文。改原文会污染这条提示词的「血缘」，而且想再来一版不同要求的还得改回去
2. **流式输出**：边生成边显示，旁边带已用时。上游不支持流式会自动回退成一次性返回（只慢那一次，之后记住这个供应商）；读流中途卡住超过 20 秒会自动中断，不会无限转圈
3. **假设可接管**：多角度补全给出的假设逐条列出，把「模型替你猜的」变成「你填一次就固化」

### 线上提示词库

- **内置 60 条**（写作 / 编程 / 分析 / 办公 / 图像 / 角色 / 学习 / 生活 8 个分类）+ **10 套模板**。模板给的是方法论：什么时候用、怎么做、容易踩的坑，不只是丢一段文本给你
- **断网可用**：目录内置在安装包里，首启就有内容；联网后可「检查更新」增量拉取新版，只下变更的分片
- **收录不覆盖你的改动**：收入个人库后来源记为「线上」，目录以后更新时卡片会显示「有更新」，但**不会自动覆盖你改过的内容**
- **可导入自己的数据集**：支持 `{items:[...]}` / `{prompts:[...]}` / 裸数组三种格式。导入的条目只存在你本机，版权与合规由你负责

### 数据放在哪

| 内容 | 位置 | 参与同步 |
| --- | --- | --- |
| 提示词库（一条一个 `.md`） | `~/AgentHub/prompts` | 是（WebDAV） |
| 优化历史（最近 50 次） | `%APPDATA%\AgentHub\prompts\history.json` | 否，本机留痕 |
| 优化风格（含自定义） | `%APPDATA%\AgentHub\prompts\styles.json` | 否，本机偏好 |
| 线上目录缓存 | `%APPDATA%\AgentHub\prompts\catalog` | 否，应用资产 |

### 怎么用

1. 打开「优化提示词」，把想改的那句话粘进去。信息很少就选「多角度补全」，已经比较完整就选「通用增强」
2. 有额外要求写在「补充要求」里，不用动原文；不知道还缺什么，就点下面的角度 chip（受众 / 场景 / 格式 / 边界 / 示例 / 验收）
3. 跑完看结果，不满意点「重新优化」或直接在下框手改；改过之后再点「重新优化」会先问一次，不会默默覆盖你的修改
4. 满意的点「保存到我的库」，正文里的 `{{变量}}` 会被自动识别成变量
5. 想直接拿现成的，去「线上提示词库」按分类翻，或者用左栏「按变量找」——从「我手上有什么材料」反查模板
6. 多台电脑：先在「设置 · WebDAV 同步」填好服务器，再到「WebDAV 同步」页跑一次

## 常见问题

**Q：为什么 Trae 不能「切到 IDE」？**
Trae 的本地登录态是 ByteCrypto 加密信封，绑定了设备密钥，无法在外部构造出合法文件。程序会诚实提示而不是写坏你的登录态。

**Q：小浣熊多账号要注意什么？**
多账号入池请统一在 AgentHub 的「OAuth 登录」里做。**不要在电脑端小浣熊软件里点「退出登录」**——商汤服务端会因此吊销旧号凭证，导致号池里的旧账号失效。

**Q：号池用 WebDAV 同步到第二台电脑后，小浣熊账号显示「需重登」怎么办？**
不用重新登录，先让它自己缓过来：小浣熊的刷新令牌是一次性轮换的（第一台每刷一次，同步过去的那份就会作废），v1.68.1 起刷新被服务端拒绝时会自动到其他设备把最新凭据取回来重试，第一台下次刷新也会立刻回传，所以**保持两台都开着、网络与 WebDAV 正常，等一轮额度刷新（默认 30 分钟）即可**。同一账号请只在 AgentHub 里登录一次：**不要在第二台电脑上用 OAuth 或客户端再登录同一个号**——那会产生第二个会话（服务端按会话互踢），连第一台也会一起掉。真掉登录时账号气泡会说明原因（服务端拒绝 / 并发抢刷 / 疑似在别处重新登录）。

**Q：点「切到 IDE」会不会打断我正在用的客户端？**
会：程序需要先关闭对应客户端，写入登录态后再自动打开（这也是为什么每次都会先弹一个确认框）。如果你此刻正在那个客户端里干活，先存盘再点。

**Q：我的凭据安全吗？**
账号 token 经 Windows DPAPI 加密后落盘，且只在主进程中流转，不暴露给界面层。所有请求只发往你所用服务的官方接口，以及你自己配置的 WebDAV 服务器，中途不经过任何第三方服务器。

**Q：没配置 WebDAV 是不是很多功能不能用？**
不是。用量统计会自动进入本地模式；技能仓库、号池管家、记忆中枢、提示词库的单机功能全部可用，WebDAV 只是「多台电脑共享」用的。

**Q：自动签到什么时候跑？**
默认关闭。开启后每天到设定时间（默认 09:00，可改）自动给全部渠道跑一遍签到/领加油包，结果按渠道分别记录，切渠道看得到各自的历史。

**Q：优化提示词时一直转圈怎么办？**
先看「设置 · 模型与网关」里有没有可用模型（没配会直接提示并给跳转入口），再看「高级」里的超时设置。流式读取时如果上游超过 20 秒不吐新内容会自动中断并说明原因，不会无限转下去。反代环境如果反复失败，可以在「配置 · 优化偏好」里关掉「流式输出」，省掉那次失败往返。

**Q：线上提示词库里的条目能直接商用吗？**
内置的 60 条与 10 套模板是自建内容，许可写在详情页的「来源与许可」里。**你自己导入的数据集**（别人的开源提示词库等）版权与合规由你负责——程序只做本地加载，不打包、不分发。

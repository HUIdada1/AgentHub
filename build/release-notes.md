## 反代网关（新渠道：ModelScope 魔搭）

- **新增 ModelScope（魔搭）渠道**：本项目首个「官方公开 API」型渠道——非逆向、无需安装任何客户端、无签名。原生 OpenAI 兼容对话（支持流式 / 工具调用 / 思考链），开箱内置 24 个实测模型（DeepSeek / GLM / Qwen / MiniMax 等）。
- **OAuth 2.0 官方授权登录**：点一次「授权」自动完成互联应用动态注册与入池，凭据 30 天自动续期（refresh token 一次性轮换已按规范处理）；授权窗顺带采集 Web 会话，推理、每日登录奖励（+200 魔粒）、绑云奖励（+50）、点赞任务（+40）全部可用。
- **兜底粘贴 ms- 令牌**：在魔搭「访问令牌」页自助创建，粘贴入池前先校验有效性并以真实用户名作账号标识。
- **每日任务自动签到**：幂等设计（按上游「今日已用」补做剩余额度），点赞受安全阀与随机抖动约束；点赞为公开星标动作，签到状态查询严格只读。
- **报错可操作**：未绑定阿里云账号、未完成实名认证两类 403 单独归类，提示直达设置页；余额不足归入积分耗尽自动换号。

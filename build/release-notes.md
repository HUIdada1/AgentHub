## 新功能

- 适配器契约固化：必需方法（cfg/models/chat/queryCredits）缺失在启动期即报错，不再留到运行期才出 "ad.chat is not a function"；契约注释块写明新增渠道的完整步骤清单
- 双表同步断言：渠道注册表与适配器注册表双向差集自测兜底，漏挂即自测失败并指出差集（防止模型被路由到无账号渠道）
- 会话式转发扩展点：适配器可声明 stateful 走 chatSession，装得下「一次客户端请求 = 多个上游请求 + 协议翻译」的渠道形态（现有渠道行为零变化）
- 渠道级错误分类扩展点：适配器可用 classifyError 处理渠道私有业务码，通用分类器保持跨渠道共用
- 全局日志脱敏：上游报错回显的 JWT / Bearer / 键值对凭据在落库前统一打码，不再进操作日志、账号错误气泡与导出 Excel
- meta 写入白名单：凭据类敏感键在写入账号元数据前剥离，凭据一律走独立加密列
- 号池同步弱口令告警：WebDAV 密码不足 8 位时记警告（不阻断同步，避免破坏既有流程）

## 修复

- 签到批量操作对残留已下架渠道的账号不再抛错拖垮整批，改为该行如实报未知渠道并继续

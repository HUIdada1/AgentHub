## 新增渠道：Qoder（国内版 / 国际版双区）

- 反代网关新增 Qoder 渠道，国内版与国际版各自独立成一个渠道（两边的账号体系与额度池互不相通），在号池页顶部切换
- 加账号四种方式都支持：官方登录页 OAuth 登录（设备码轮询，登录环节**无需本机安装客户端**，也不用粘贴回调）、从本机软件导入（直接读取客户端已登录的设备凭据）、JSON/ZIP 文件、粘贴 JSON
- 每日 Credits 一键领取：号池页按钮为「领 Credits」（每日 100，10:00 UTC+8 刷新，领取后 30 天有效；重复点击按「今日已领」处理，不会误报失败）
- 余额按 Credits 浮点显示（不再被整数化，小额消耗看得见），渠道卡与总览页同步标注单位；号池同步页的「只同步某一个渠道」下拉也补上了 Qoder 两项
- 推理请求的签名头与请求体编码由客户端内置 wasm 实时生成，AgentHub 首次调用时自动从本机已安装客户端提取并按版本缓存（客户端升级后自动重建，无需重装本应用）；**安装位置自动识别**——默认安装目录、客户端自带启动器的版本目录、自定义安装路径都能定位到

## 说明

- 本次为功能版本，既有渠道（Trae / WorkBuddy / 小浣熊 / ZCode）行为与配置不受影响
- 国际版免费额度不含 DeepSeek / GLM Flash 系列，需订阅覆盖才有可用模型（界面已注明）
- 只导入凭据、本机没有安装对应 Qoder 客户端时，账号可以入池但无法发起请求（签名依赖客户端能力），装回客户端即可恢复；每日领取同样需要客户端提供风控身份
- Qoder 渠道的凭据与请求只在本机与你自己的账号之间流转，不经过任何第三方服务器

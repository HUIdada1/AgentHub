## 新功能
- 反代网关 · 跨渠道故障转移（Failover + Failback）：渠道报 503/429 或号池耗尽时，请求内自动跳到其他渠道继续用（按余额充足度排序选备选），客户端完全无感；连续 2 次「真实尝试后打光」才把整个渠道降级（默认 120 秒），降级期内所有新请求（含指定路由的 Key）直接走备选渠道不再撞墙
- 降级到期自动半开回切：流量自动回到恢复且余额最充足的渠道；回切后再失败退避时长翻倍（120s → 240s → 480s → 封顶 15 分钟），防止上游未恢复时在两个渠道间反复横跳；请求成功一次即清零退避状态
- 渠道耗尽/降级后所有渠道仍不可用时，错误信息带完整轨迹（如「已尝试 3 个渠道（trae→workbuddy_ai→zcode）均不可用」）；成功请求的流水备注记录切换轨迹（如 failover:trae→workbuddy_ai）
- 号池页渠道卡新增降级徽标（剩余秒数倒计时 + 鼠标悬停看原因）；渠道降级/恢复实时事件推送
- 设置页「服务与路由」新增故障转移配置组：总开关、单请求最多尝试渠道数（默认 3）、降级基础时长与封顶（失败翻倍）

## 修复
- 渠道级 WAF 拦截 / 白名单 11128 从「固定 60 秒 + 直接报错」升级为「指数退避 + 自动跳备选渠道」，不再白白失败一笔请求
- 跨渠道跳转时按渠道重算反向模型映射（此前换渠道沿用第一个渠道的目标模型名会打错模型）
- 纯本地打光（全冷却/耗尽/模型级负缓存）不再降级渠道：号池状态是实时派生的，渠道级再缓存一份会把已恢复的渠道错误地挡在门外（自测回归中实测发现并根治）

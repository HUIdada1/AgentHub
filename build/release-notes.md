## 新功能
- 模型目录 · 上下文长度 K/M 缩写显示：表格里显示 131K / 1M，聚焦自动展开完整数字（131072），可直接输入 128K / 1.5M 这样的缩写落库；悬停输入框可看当前精确值
- 模型目录 · 能力 / 来源渠道列悬停浮窗：标签被列宽收纳时悬停即展开完整清单（图片输入 / 思考链 / 工具调用；来源渠道逐个列出，多源时才启用）

## 修复
- 模型目录 · 4K 屏（Windows 200% 缩放）下固定列宽溢出被静默裁切根治：状态列 48→68px（开关不再只剩半截）、渠道覆盖列 110→124px（select 完整显示）、上下文 / 思考强度列补齐「自」标记的占位宽度；校止后固定列合计在任何支持窗口尺寸下均不溢出
- 以上三项来自社区 PR #13（by imalti0r），合并时修正了渠道覆盖列 118px 仍差 6px 的算术、补齐上下文与思考强度两列「自」徽标的漏算，并顺手处理 999999 显示成 1000K 的进位边界

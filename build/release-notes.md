## 性能与架构加固

- **记忆打包/解包挪进 Worker 独立工作线程（PR #57 整合加固）**：
  - 彻底解决大记忆库在 WebDAV 同步及「导出备份」期间，主进程单线程 gzip 压缩占死事件循环（冻结数十秒、连带挂起 UI 与 9527 模型代理网关）的问题，事件循环延迟由 10s+ 降至 4ms 极速响应。
  - **Asar 兼容与安全引导**：采用动态源码传输与临时目录加载机制，完全规避 Electron 生产环境 Worker 无法直接加载 asar 内部相对路径的限制。
  - **审核加固护栏**：新增单文件瞬态删除容错，避免并发清理导致整包构建失败；追加 5 分钟超时熔断护栏与双层临时目录自动回收，防止 Worker 挂死。
  - **真实时间戳还原（mtime）**：废除 `.packstage` 冗余整树复制，按原始文件直接打包并记录真实修改时间，解包自动还原 `mtime`，彻底修复远端解包文件被误判为“刚同步”导致的冲突裁决系统性偏向远端的问题。

## 功能与体验优化

- **同步日志时间戳补回与秒级精度（PR #59 整合优化）**：
  - 修复此前 `formatDateTime` 因返回 11 字符短格式被 `slice(11)` 误截出空字符串导致前端日志无时间戳的问题。
  - 扩展全局时间格式化工具，补全秒级精度（`MM-DD HH:mm:ss`）与非法时间戳容错兜底，日志耗时比对更直观。
- **记忆时效性检查与关联文件变更预警**：
  - 支持写入记忆时锚定关联本地文件路径与时间戳快照；当关联源码在后续被外部修改后，记忆检索与明细展示时自动发出时效过时预警，防止根据旧记忆误回退代码。
- **原生支持 Google Antigravity Agent 接入**：
  - 完整适配 Antigravity 的 MCP 注册、GEMINI.md 规则注入与记忆工具集成。

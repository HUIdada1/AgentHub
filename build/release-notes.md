# v1.91.0 更新说明

## 新增第六大板块「本地网关」

把号池里已配置的渠道账号包装成**一个本地 OpenAI / Anthropic 兼容端点**：把 `base_url` 指到 `http://127.0.0.1:9527/v1`，你的 IDE、脚本或自建服务就能直接用上号池的额度。

- **账号体系复用号池**（只读）：不建第二套账号模型，账号的唯一事实源仍是「号池管家」；号池里停用的账号在网关侧立即熔断。
- **对外协议**：`GET /v1/models`、`POST /v1/chat/completions`（流式）、`POST /v1/messages`（Anthropic，流式），以及免鉴权的 `GET /health` 探活。鉴权同时接受 `Authorization: Bearer` 与 Anthropic 的 `x-api-key`。
- **六个页面**：总览（状态 / KPI / 三步引导 / 渠道在线一览）、服务与密钥、路由与渠道、模型目录、请求日志、接入与文档。
- **API Key 不明文落库**：库里只存 `HMAC-SHA256(raw + 内部密钥)` 与展示前缀，完整 Key 只在创建时出现一次。
- **端口冲突自愈**：9527 被占时自动往后探 9528 ~ 9530，界面显示的是实际生效端口。
- **默认不自启、默认只听回环**：装了不等于对外开端口；`autostart` 默认关、`bind` 默认 `127.0.0.1`。
- **渠道路由**：智能 / 固定 / 轮询 / 评分四种策略 + 故障转移与冷却退避；模型别名与覆盖可把上游真实模型名映射成你想对外暴露的名字。
- **请求日志与延迟分位**：按渠道 / 状态筛选，可导出 JSONL 或 CSV。
- **出站指纹脱敏（敏感判断）**：上游对请求体是按**逐字精确匹配**审核的（不是语义审核），客户端注入的固定模板句、计费头字段名、以及裸错误码出现在报文里就会整单拦截。开启后网关在转发前改写这些指纹——表头键值整段删除、`cc_*` 键值整段删除、模板句只换一个词（如 `official CLI for Claude` → `official CLI tool for Claude`）、`11128` 改写为 `11-128`——对话内容与语义都不变；命中的请求在请求日志的「敏」列打标，悬停可看命中了哪几条规则。默认开，只改发给上游的副本。
- **停用板块即停服务**：模块开关关掉会立刻关闭监听并释放连接。

> 旧「反代网关」的独立进程与 Docker 形态仍然停止维护；本板块是其 API 转发能力的接替实现，形态是主进程内嵌、与号池只读对接。同样不跟进上游协议与风控策略变化，可用性不承诺。

## 号池管家：cockpit-tools 账号导入导出兼容

- **导出**：账号导出弹窗新增格式单选——「号池自带格式」或「cockpit-tools 格式」。后者导出 `cockpit-tools.account-transfer` v1 转移包，可由 cockpit-tools 的「导入账号转移包」直接读入；没有对应平台的渠道会跳过并如实告知跳过了几个。
- **导入**：识别 cockpit-tools 转移包（按平台映射入池），也支持直接粘贴某个平台的账号 JSON 数组。转移包版本不支持时给出可执行的提示，而不是笼统失败。

## 修复（本轮纯静态审查发现）

本次对最近的全部改动做了一遍逐文件的静态审查，发现并修掉了一批「接线即崩」的问题，其中本地网关模块在接线前处于不可用状态：

- **本地网关**：`aggregateOpenaiEvents` / `aggregatedUsage` 两个函数只有调用没有定义（每次请求必然抛错）；转发时凭据取的字段与号池存储层签名不匹配（每次转发都以「凭据缺失」失败）；API Key 的 HMAC 密钥取自一个并不存在的接口，实际退化成硬编码常量；`handleMessages` 重复定义，生效的那份会把 SSE 帧写进非流式响应体。
- **本地网关**：并发闸门在异常路径上永久泄漏（连续失败十几次后整个网关永久 429）；路由的 score 策略恒为 0（取了一个不存在的字段），轮询 / 智能两个分支从未实现；并发闸门与超时未映射 504、流式失败被静默截断；`markSucceeded` 定义了却从未被调用，导致退避只增不减。
- **本地网关**：`x-api-key` 头声称兼容但实际没读（Claude Code 必 401）；admin / readonly 令牌用普通相等比较，且 readonly 令牌可以发起消耗额度的写请求。
- **本地网关**：SSE 实际是「先攒满再回放」，不是真流式；请求体大小上限因单位换算写成 `NaN` 而完全失效；客户端断开后请求 Promise 永不结束。
- **本地网关**：模块配置的 `patch` 会把整份配置写回，读不到完整配置时有抹掉其它模块配置的风险。
- **第六板块的注册链**：框架配置的 `moduleOrder` 已知集合没有 `localgw`，后端归一化时会把该 key 静默剔除——**第六板块在左栏根本不显示**；前端 `orderedModules` 只按 `moduleOrder` 映射取模块，缺 key 时没有任何兜底。两处都已补齐对称兜底。
- **配置页模块排序**：列表渲染的是「可启停模块」子集，上下移 / 拖拽却用可视列表下标去交换 `moduleOrder`，两者长度不同会换错行（localgw 不在末位时整列错位）。
- **提示词库**：线上目录「检查更新」在分片下载失败时仍把远端索引落盘，导致版本号先跳新值、失败分片**永远补不回来**；若干处渲染期计算对缺字段的接口返回值没有兜底，会带崩整页。

## 升级提示

# v1.90.0 更新说明

## 提示词库：多角度补全、流式输出、线上目录

本版是提示词库（第五大板块）的二期，把「怎么把一句话说清楚」这件事补完整。

## 新增风格「多角度补全」

- 原话很短时用它（比如「帮我写个周报」）：先按 9 个角度扫描缺口——目标、受众、场景、素材、内容维度、形式、边界、失败模式、交付验收——再用合理默认值补齐，最后按规范骨架输出。
- **不编事实**：人名、机构、数字、日期、金额、型号一律留成 `{{变量}}`，不替用户瞎猜。
- **假设看得见**：模型替你做的假设最多 3 条，单独列在结果下方，每条都写「若不成立会变成什么样」；在结果框里选中对应文字点「→ 变量」，就能把它变成可填写的变量。
- 内置风格从 5 套增加到 6 套。

## 流式输出

- 边生成边显示，旁边带已用时。原来那句「限流或 5xx 时后端会自动退避重试」已移除——等待中的用户只关心跑了多久。
- 三种上游协议都支持流式：Chat Completions、Anthropic、Responses。
- **上游不支持流式会自动回退**成一次性返回（只慢那一次，之后记住这个供应商）；读流中途 20 秒没有新内容会自动中断并说明原因，不会无限转圈。
- **取消会真的中断上游请求**，不再白烧 token。
- 反代环境反复失败时，可在「配置 · 优化偏好」关掉「流式输出」。

## 新增「补充要求」

- 想加一句「面向不懂技术的老板」，写在原文框下面的「补充要求」里即可，不用改原文——改原文会污染这条提示词的血缘，想再来一版不同要求的还得改回去。
- 选中「多角度补全」时，补充要求下方会多出 6 个角度 chip（受众 / 场景 / 格式 / 边界 / 示例 / 验收），点一下就把对应引导语填进去。

## 新增「线上提示词库」页面

- 内置 60 条精选提示词（写作 / 编程 / 分析 / 办公 / 图像 / 角色 / 学习 / 生活 8 个分类）+ 10 套模板。模板给的是方法论：什么时候用、怎么做、容易踩的坑，不只是丢一段文本给你。
- 纯客户端静态目录：随安装包分发，断网也能用；联网后可「检查更新」增量拉取新版，只下变更的分片。
- 一键「收入我的库」，来源记为「线上」；目录以后更新时卡片会显示「有更新」，但**不会自动覆盖你改过的内容**。
- 支持导入自己的数据集（`{items:[...]}` / `{prompts:[...]}` / 裸数组），导入的条目只存在本机。
- 左栏「按变量找」：从「我手上有什么材料」反查模板，而不是从「我想要什么」正查。

## 界面

- 原文输入框高度减半，让出的空间给结果框——结果才是要盯的地方。
- 结果区新增「结构预览」：按 `##` 分节渲染成只读卡片，一眼看出哪一层是空的。

## 顺带修复

## 修复：更新安装确认机制——不再「启动了就算成功」

- **问题**：1.87.2 起点击「立即重启安装」后偶发应用退出、但新版本没装上的现象（1.88.0 真机取证：两次点击安装器均无果，且无崩溃记录、无杀软拦截记录）。根因是安装器启动后应用只等 200 毫秒就认定「已启动」随即退出——安装器进程是否真的完成安装，应用端全程无感知，一旦安装器在窗口期内意外死亡（扫描挂起、早期退出等），既装不上也无从取证。

# v1.87.2 更新说明

## 更新链路再加固：安装包「搬台面」

- 在 1.87.1 自管安装器启动的基础上再加一道保险：**下载完成立即把安装包复制到系统临时目录（`%TEMP%\AgentHub-update`）的副本，安装时优先从副本启动**。
- 背景：安全软件对「刚从网络下载的未签名安装包」所在的更新缓存目录盯得最紧，安装包刚落盘就被扫描锁定时，安装器启动会撞上文件占用错误。提前复制一份到临时目录，既是完整读盘预热（扫描锁就地解开），也把启动落点换出了缓存目录，命中锁定的概率大幅降低。
- 副本复制完成后同样做整包 sha512 校验，复制中断的文件绝不会被拿去安装；副本失败时自动回退原路径，不影响更新可用性。
- 1.87.1 的既有保障不变：启动前校验、失败自动重试、提权回退、失败不退出应用并在更新中心给出明确原因，更新组件内部日志全程记录到 `logs/crash.log`。

# v1.87.1 更新说明

## 修复：更新安装「应用退出后新版本没装上、也没自动重启」

- **问题**：点击「立即重启安装」或退出时自动安装后，应用退出、但新版本没有装上、也没有自动重启，且没有任何报错。根因是安装器启动此前交给 electron-updater 的内部实现——它发出启动指令后立即退出应用，一旦安装器启动失败（杀毒软件对刚下载安装包的实时扫描锁、文件占用等），错误信息随应用进程一起丢失，无从排查。

## 提示词库（第五大板块）

- **优化提示词**：上方输入原文、中间按钮、下方出结果。可选优化风格（内置 5 套：通用增强 / 更简洁 / 更结构化 / 补全约束 / 面向编码任务）、选模型，并可调长度上限、温度、最大输出、超时与目标场景；结果可一键复制、重新优化、保存到库、与原文并排对比。
- **个人提示词库**：两级分类与标签、全文搜索、收藏、卡片/列表视图、批量操作与回收站；每条都有版本历史与血缘（记录从哪条原文、哪个风格、哪个模型生成）。
- **优化历史**：最近 50 次记录（失败的也留痕并写明原因），可回填、复制、删除。
- **复用平台模型**：优化直接走「设置 · 模型与网关」里已配置的供应商与模型池，沿用降级链、失败重试与用量记账，不需要额外配置。

## 跨设备同步（独立链路）

- 与技能仓库 / 用量统计 / 号池管家 / 记忆中枢**各自独立**、互不阻塞，在「设置 · WebDAV 同步」里有自己的根目录。
- **冲突默认自动合并**（默认新者优先），被放弃的那一份会写入该条目的版本历史，可在同步页逐条查看并改判；也支持一键「自动合并全部」，或改为全部人工裁决。
- 同步周期在「设置 · 同步时间 → 提示词库」按小时设置，默认每 4 小时，默认开启。
- 回收站删除以墓碑方式同步，不会在别的设备上「复活」；远端清单异常为空时会停下来而不是覆盖。

## 外置插件与窗口

- 插件可声明桥接资源与内嵌界面地址，界面直接嵌入主区域（CSP 仅放行本机回环地址）。
- 无边框窗口 + 自绘标题栏：版本 / 作者 / Star / 主题 / 设置，以及最小化 / 全屏 / 关闭。

## 升级提示

- 覆盖安装即可。本版不改动既有四大板块的数据与配置；提示词库默认库目录为 `~/AgentHub/prompts`，首次使用会自动创建，本机偏好（优化风格与历史）另存于用户数据目录，不参与同步。

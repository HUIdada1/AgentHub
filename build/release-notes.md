## 紧急修复

- **修复记忆中枢模块加载失败**：上一版合并时 `memory_export` 的返回值与函数闭合在冲突解决中丢失，入口文件语法错误导致整个记忆模块加载即抛异常。本版已补回，并复核同批合并的全部文件改动。
- **修复「某天记忆」列表时间列显示为空**：与同步日志同源的短格式截断问题（`formatDateTime` 返回恰 11 字符，被 `slice(11)` 误截出空串），改为从正确位置取 `HH:mm`。
- **时效锚定解析加固**：`@scope/pkg`、`assets/icon@2x.png` 这类路径本身含 `@` 的关联文件，不再被误判为「路径@时间戳」锚定串，消除时效预警误报「已删除/重命名」与漏检的边界。
- **记忆运行时自测断言对齐**：导入来源断言由写死数量改为校验核心来源齐全，版本扩充来源后不再误报。
- 若你的 v1.45.0 无法启动，属于上述模块加载问题所致，请到 Releases 页手动下载本版安装包覆盖安装。

## 上一版（v1.45.0）功能要点

- **记忆打包/解包挪进 Worker 独立工作线程**：解决大记忆库在 WebDAV 同步及「导出备份」期间主进程冻结（事件循环延迟 10s+ → 4ms），并废除冗余暂存复制、按原始文件真实 mtime 打包与还原，冲突裁决不再系统性偏向远端。
- **同步日志时间戳补回与秒级精度**：修复日志行因截断丢失时间戳的问题，扩展全局时间格式化工具支持 `MM-DD HH:mm:ss` 与非法时间戳容错兜底。
- **记忆时效性预警**：写入记忆可锚定关联本地文件与时间戳快照；关联源码被外部修改后，记忆检索与明细展示自动发出过时预警，防止依据旧记忆误改代码。
- **原生支持 Google Antigravity Agent 接入**：适配其 MCP 注册、GEMINI.md 规则注入与记忆工具集成。

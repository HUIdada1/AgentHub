# v1.86.0 更新说明

本版新增「外置插件」能力：设置里可以导入插件包，插件以独立进程运行、独立更新、独立卸载，不参与主程序的版本节奏，也不影响主程序自身的任何功能。

## 外置插件（设置 · 模型与网关 → 底部「外置插件」）

- **导入即安装**：点右侧加号选择插件包（.zip），安装完成后左侧栏出现对应入口；未安装时只显示一块空态提示，不占位、不报错。
- **独立启停与更新**：可单独启用、停用、更新、卸载。更新为原地替换，插件数据与启用状态保留；卸载只移除程序本体，数据目录仍在。
- **版本互不约束**：插件有自己的版本号，主程序只校验插件声明的兼容区间；主程序升级不会强制插件跟进，插件升级也不需要重装主程序。
- **打开即运行**：点击侧栏入口时若插件未运行会先自动拉起，再打开其界面窗口，无需手动启停。

## 左侧栏

- **插件入口位置由插件自身声明**：可挂在指定模块之后，默认紧跟在号池管家下方；没有安装插件时该位置不渲染任何节点。
- **模块区可滚动**：模块数量变多或窗口变矮时，模块列表区域独立滚动，品牌区与下方概况卡片不会被挤压。

## 稳定性

- 插件崩溃后按退避策略自动重启，短时间连续失败则停止重试并记录原因，不会反复拉起。
- 退出主程序时一并回收插件进程（含其派生的子进程），不留孤儿进程占用端口。
- 插件包损坏、版本不兼容、缺少清单、安装中断等情况均有明确提示，且一律不影响主程序启动与其它模块。
- 主程序不内置任何插件代码，安装包内不含插件本体。

## 升级提示

- 覆盖安装即可。本版未安装插件时，界面与上一版行为一致，无需任何配置。

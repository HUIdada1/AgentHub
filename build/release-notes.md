# v1.90.0 更新说明

## 提示词库：多角度补全、流式输出、线上目录

本版是提示词库（第五大板块）的二期，把「怎么把一句话说清楚」这件事补完整。

## 新增风格「多角度补全」

- 原话很短时用它（比如「帮我写个周报」）：先按 9 个角度扫描缺口——目标、受众、场景、素材、内容维度、形式、边界、失败模式、交付验收——再用合理默认值补齐，最后按规范骨架输出。
- **不编事实**：人名、机构、数字、日期、金额、型号一律留成 `{{变量}}`，不替用户瞎猜。
- **假设看得见**：模型替你做的假设最多 3 条，单独列在结果下方，每条都写「若不成立会变成什么样」；在结果框里选中对应文字点「→ 变量」，就能把它变成可填写的变量。
- 内置风格从 5 套增加到 6 套。

## 流式输出

- 边生成边显示，旁边带已用时。原来那句「限流或 5xx 时后端会自动退避重试」已移除——等待中的用户只关心跑了多久。
- 三种上游协议都支持流式：Chat Completions、Anthropic、Responses。
- **上游不支持流式会自动回退**成一次性返回（只慢那一次，之后记住这个供应商）；读流中途 20 秒没有新内容会自动中断并说明原因，不会无限转圈。
- **取消会真的中断上游请求**，不再白烧 token。
- 反代环境反复失败时，可在「配置 · 优化偏好」关掉「流式输出」。

## 新增「补充要求」

- 想加一句「面向不懂技术的老板」，写在原文框下面的「补充要求」里即可，不用改原文——改原文会污染这条提示词的血缘，想再来一版不同要求的还得改回去。
- 选中「多角度补全」时，补充要求下方会多出 6 个角度 chip（受众 / 场景 / 格式 / 边界 / 示例 / 验收），点一下就把对应引导语填进去。

## 新增「线上提示词库」页面

- 内置 60 条精选提示词（写作 / 编程 / 分析 / 办公 / 图像 / 角色 / 学习 / 生活 8 个分类）+ 10 套模板。模板给的是方法论：什么时候用、怎么做、容易踩的坑，不只是丢一段文本给你。
- 纯客户端静态目录：随安装包分发，断网也能用；联网后可「检查更新」增量拉取新版，只下变更的分片。
- 一键「收入我的库」，来源记为「线上」；目录以后更新时卡片会显示「有更新」，但**不会自动覆盖你改过的内容**。
- 支持导入自己的数据集（`{items:[...]}` / `{prompts:[...]}` / 裸数组），导入的条目只存在本机。
- 左栏「按变量找」：从「我手上有什么材料」反查模板，而不是从「我想要什么」正查。

## 界面

- 原文输入框高度减半，让出的空间给结果框——结果才是要盯的地方。
- 结果区新增「结构预览」：按 `##` 分节渲染成只读卡片，一眼看出哪一层是空的。

## 顺带修复

- 「深层画像 → 重新生成画像」按钮把点击事件当成维度参数传了进去，导致这次请求的维度是个事件对象。
- 记忆中枢首次运行页在注入失败时读不到后端返回的具体原因，只显示笼统文案。

## 升级提示

- 覆盖安装即可。提示词库一期数据（库目录 `~/AgentHub/prompts`、优化风格、优化历史）完全兼容，无需迁移。
- 内置目录缓存在用户数据目录下，不参与 WebDAV 同步；「检查更新」拉不到新内容时会静默使用内置版本，不影响使用。

# v1.89.3 更新说明

## 修复：号池华为云（CodeArts）登录 404

- **问题**：发起华为云 OAuth 登录后，浏览器打开授权页直接 404。根因是华为云已下线旧版授权入口（`codearts.huaweicloud.com/login` 实测 404），旧链路从第一步就走不通，与本地端口、代理均无关。
- **修复**：授权流程整体迁移到新版门户 `/portal/authorize`——client_id 更换为官方 IDE 扩展同款的 `codearts-agent`，回调改传端口号由门户自行拼接回调地址，并补齐官方扩展一致的登录身份参数；换码与续期表单同步切换。
- **回调端口要求**：新版门户只接受 ≥10000 的回调端口，CodeArts 渠道回环端口低于该值时自动换高位端口重试；其余渠道不受影响。
- **存量账号注意**：旧流程签发的登录凭据续期可能失效，受影响的 CodeArts 账号请在号池中**重新登录一次**（失败会给出明确报错并进入冷却，不会盲目重试）。
- **顺带修复**：回环监听端口被占用时退避随机端口的路径存在监听器被提前摘除的问题，会导致登录静默卡住无响应——本次重写后根治，所有走回环回调的渠道一并受益。

# v1.89.2 更新说明

## 完善：DSH 接入的机器适配加固

- **profile 识别改为特征判定**：`~/.dsh/profiles/` 下混有 `node_modules`、隐藏目录等非 profile 内容，此前会被一并当作 profile 写入 patch 文件。现在只认「含 cordis.yml（基础层）或 cordis.patch.yml（patch 层）」的目录，动态发现、桌面端优先——无论用户机器上有几个、什么名字的 profile 都能正确覆盖。

- `js-yaml` 显式声明为依赖（此前为传递依赖，块级 YAML 自证依赖它）。

# v1.89.1 更新说明

## 修复：DSH（DeepSeek Harness）自动接入无效

- **问题**：记忆中枢对 DSH 的自动接入把 MCP 配置写到 `~/.dsh/mcp.json`，但 DSH 并不读取该文件（社区反馈 + 本地对其安装包的全文检索交叉确认），导致记忆工具永远不出现在 DSH 会话里——配置看似成功，实际「指令到了、工具没到」。
- **修复**：接入方式改为 DSH 官方的 profile patch 层——把 agenthub-memory 的 MCP 服务器以受控注释块写入 `~/.dsh/profiles/<profile>/cordis.patch.yml`（insert `@deepseek-ai/dsh-mcp-client`），与官方插件机制同构。覆盖本机全部已存在的 profile（桌面端优先）；profile 从未改过 patch 时会按官方头注释新建文件。
- **托底**：写入前块文本先过 YAML 自证；patch 文件顶层非数组、受控块起止注释不配对一律拒绝注入并保留备份；别人的受控块（如其它工具注入的）原样保留；检测到旧的 `~/.dsh/mcp.json` 残留时给出清理提示；未发现 DSH profile 时明确引导先运行一次 DSH。注入全程备份可回滚。

# v1.89.0 更新说明

## 修复：更新安装「应用退了、新版本没装上」的死结

- **问题**：1.86 以来的历次热更新中反复出现「点击更新后应用退出，但新版本没有装上」，且无任何报错可查。1.88.x 真机取证（系统事件日志 + 主进程注入实验）定位到根因：安装器启动时检测到应用仍在运行，会尝试关闭它——Electron 多进程应用完全退出需要一到两秒，慢于安装器的进程轮询，安装器判定「应用无法关闭」后在静默模式下直接放弃：不安装、无界面、无日志，只留下已退出的旧应用和没装上的新版本。
- **修复**：安装器的启动时机整体后移——从「应用还在运行时」移到「应用完全退出的最后一刻」。此刻系统进程表里已经没有 AgentHub，安装器不再需要关闭任何进程，启动即安装，装完自动启动新版本。此前几版的重试/校验/副本预热等加固全部保留。
- **新增安装哨兵**：安装器启动后应用即退出，安装成败由下次启动判定并记入 `logs/crash.log`，任何环节的失败都不再无据可查。

# v1.88.1 更新说明

## 修复：更新安装确认机制——不再「启动了就算成功」

- **问题**：1.87.2 起点击「立即重启安装」后偶发应用退出、但新版本没装上的现象（1.88.0 真机取证：两次点击安装器均无果，且无崩溃记录、无杀软拦截记录）。根因是安装器启动后应用只等 200 毫秒就认定「已启动」随即退出——安装器进程是否真的完成安装，应用端全程无感知，一旦安装器在窗口期内意外死亡（扫描挂起、早期退出等），既装不上也无从取证。
- **修复**：安装器启动改为**等待其真实退出并核对退出码**——退出码为 0（安装器报告完成）应用才退出；非 0 记入日志并重试，仍失败回退提权方式，全程在更新中心给出明确原因。安装器长时间未退出（慢盘、静默卸载旧版等）超过 120 秒按「仍在运行」放行退出，不影响其后台继续安装。
- 安装器正常 6~10 秒完成，此修复仅让应用多陪它几秒再退；下载、校验、副本预热、失败重试等 1.87.x 既有保障全部不变。

# v1.87.2 更新说明

## 更新链路再加固：安装包「搬台面」

- 在 1.87.1 自管安装器启动的基础上再加一道保险：**下载完成立即把安装包复制到系统临时目录（`%TEMP%\AgentHub-update`）的副本，安装时优先从副本启动**。
- 背景：安全软件对「刚从网络下载的未签名安装包」所在的更新缓存目录盯得最紧，安装包刚落盘就被扫描锁定时，安装器启动会撞上文件占用错误。提前复制一份到临时目录，既是完整读盘预热（扫描锁就地解开），也把启动落点换出了缓存目录，命中锁定的概率大幅降低。
- 副本复制完成后同样做整包 sha512 校验，复制中断的文件绝不会被拿去安装；副本失败时自动回退原路径，不影响更新可用性。
- 1.87.1 的既有保障不变：启动前校验、失败自动重试、提权回退、失败不退出应用并在更新中心给出明确原因，更新组件内部日志全程记录到 `logs/crash.log`。

# v1.87.1 更新说明

## 修复：更新安装「应用退出后新版本没装上、也没自动重启」

- **问题**：点击「立即重启安装」或退出时自动安装后，应用退出、但新版本没有装上、也没有自动重启，且没有任何报错。根因是安装器启动此前交给 electron-updater 的内部实现——它发出启动指令后立即退出应用，一旦安装器启动失败（杀毒软件对刚下载安装包的实时扫描锁、文件占用等），错误信息随应用进程一起丢失，无从排查。
- **修复**：安装器启动改为自己接管——启动前先整包校验 sha512 并读盘预热（化解杀软扫描锁）；启动失败自动重试（1.5 秒间隔最多 3 次），仍失败回退提权方式拉起；任何一步失败应用**都不再退出**，更新中心会显示明确原因，可直接重试。更新组件的内部日志也会记入 `logs/crash.log`，后续更新问题可精确定位。

# v1.87.0 更新说明

本版新增第五大板块「提示词库」：一个本机优先、可跨设备同步的提示词资产库，外加一个对标「增强提示词」的优化工作台。同时带来外置插件的桥接与内嵌界面、以及无边框自绘标题栏。

## 提示词库（第五大板块）

- **优化提示词**：上方输入原文、中间按钮、下方出结果。可选优化风格（内置 5 套：通用增强 / 更简洁 / 更结构化 / 补全约束 / 面向编码任务）、选模型，并可调长度上限、温度、最大输出、超时与目标场景；结果可一键复制、重新优化、保存到库、与原文并排对比。
- **个人提示词库**：两级分类与标签、全文搜索、收藏、卡片/列表视图、批量操作与回收站；每条都有版本历史与血缘（记录从哪条原文、哪个风格、哪个模型生成）。
- **优化历史**：最近 50 次记录（失败的也留痕并写明原因），可回填、复制、删除。
- **复用平台模型**：优化直接走「设置 · 模型与网关」里已配置的供应商与模型池，沿用降级链、失败重试与用量记账，不需要额外配置。

## 跨设备同步（独立链路）

- 与技能仓库 / 用量统计 / 号池管家 / 记忆中枢**各自独立**、互不阻塞，在「设置 · WebDAV 同步」里有自己的根目录。
- **冲突默认自动合并**（默认新者优先），被放弃的那一份会写入该条目的版本历史，可在同步页逐条查看并改判；也支持一键「自动合并全部」，或改为全部人工裁决。
- 同步周期在「设置 · 同步时间 → 提示词库」按小时设置，默认每 4 小时，默认开启。
- 回收站删除以墓碑方式同步，不会在别的设备上「复活」；远端清单异常为空时会停下来而不是覆盖。

## 外置插件与窗口

- 插件可声明桥接资源与内嵌界面地址，界面直接嵌入主区域（CSP 仅放行本机回环地址）。
- 无边框窗口 + 自绘标题栏：版本 / 作者 / Star / 主题 / 设置，以及最小化 / 全屏 / 关闭。

## 升级提示

- 覆盖安装即可。本版不改动既有四大板块的数据与配置；提示词库默认库目录为 `~/AgentHub/prompts`，首次使用会自动创建，本机偏好（优化风格与历史）另存于用户数据目录，不参与同步。

## 新功能

- 新增 **CatPaw（美团）** 反代渠道：上游是一套有状态会话协议（提交消息 → 执行中 → 流式执行 → 工具循环 → 轮次结束），适配器走本项目的「会话式转发」扩展点，是第一个使用该形态的渠道；支持长会话增量提交（客户端历史只传新增部分）、工具调用与结果续接、思考链、图片输入（>60KB 的内联图自动压缩）、积分查询与远程模型目录
- CatPaw 账号接入：支持「从本机客户端导入登录态」（读取 CatPaw 桌面端登录态并**实时跟随**——客户端重新登录或换号后自动生效）与「粘贴登录态 JSON / Cookie 串」两种方式；渠道图标、号池卡片、模型目录、流水页均自动出现，无需额外配置
- 号池页对无签到活动的渠道不再显示签到入口（CatPaw 本家无签到，点了只得到一条无意义结果）

## 修复

- **修复 v1.59.0 起「任何上游报错落库都抛 TypeError」的回归**：日志脱敏模块的导出形态与调用点不一致，导致上游的真实错误被替换成 `redact is not a function` 发给客户端、操作日志静默丢失（渠道换号的端到端自测即栽在这里）；已改为与导出对齐
- 修复模型页「自定义思考强度」在 CatPaw 模型上直接把请求打成 400：网关六档（极低/低/中/高/极高/最高）自动归并到本家三档，关闭思考按「不发送档位」处理
- 修复 CatPaw 账号在登录态失效时点「重登」会走 WorkBuddy 授权流程（渠道串味）：无 OAuth 的渠道已显式挡住，界面改为引导「客户端重新登录 → 重新扫描 → 导入」
- 修复「添加账号」弹窗对无 OAuth 渠道停在不可见页签的问题（默认落在该渠道第一个可用方式）

## 说明

- CatPaw 无签到、无凭据自动续期：登录态过期时在 CatPaw 客户端重新登录即可（本机导入的账号会实时跟随），或重新粘贴登录态
- 客户端身份常量与超时（工具版本、客户端版本、请求超时等）在「规则文件 → headers.json」的 catpaw 段，客户端升级后改配置即热生效，无需等待发版
- 新增 `tools/proxy-catpaw-selftest.cjs` 自测：覆盖协议层纯函数、会话注册表（TTL / 淘汰 / 多账号身份隔离）、轮次状态机三条规则与三条硬约束、图片压缩降质序列，以及**过网关端到端**（路由 → 会话式转发 → 流式 / 非流式 → 记账 → 积分刷新）

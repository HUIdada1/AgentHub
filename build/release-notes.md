# v1.85.0 更新说明

本版把「模型与网关」从记忆中枢搬到全局设置，模型来源收敛为「自定义供应商 → 内置降级档」；计费价格源改成三张同构卡片，点「立即拉取」即生效。（v1.84.0 的改动一并包含在本版）

## 模型与网关（设置 · 模型与网关）

- **迁出记忆中枢**：供应商与模型映射、可用性探测集中到「设置 · 模型与网关」，记忆中枢只留按标签的路由与降级链，两件事不再挤在同一个面板里。
- **来源固定两档**：自定义供应商 → 内置降级档，档位语义固定、不可拖拽排序。反代网关已在 v1.83.0 改造为号池管家，本机网关档没有可用上游，本版正式下线。
- **存量配置自动归一化**：读到带 gateway 的旧来源顺序时就地按固定序渲染并静默落盘一次，解析链不再多试一次注定失败的档位。
- **拦截口径一致**：可用性探测同步去掉网关档，两档都不可用才拦。
- **设置弹窗按页签自适应宽度**：模型与网关页更宽（1040px），长表格不再挤。

## 计费

- **三张同构价格源卡片**：官方倍率预设（basellm）、models.dev 预设、远程价格表（Wei-Shaw），各自独立开关 + 检查间隔 + 立即拉取，链接全部内置，不用再填站点地址。
- **拉取即生效**：「立即拉取」在后台拉取并直接应用差异（新增与调价马上落库），不再弹预览确认框。
- **三层来源合并**：official > modelsdev > remote，三套各写各的价格段，谁生效由排序键决定；旧 newapi 段保留可读，老配置自动迁移到 `billing.sources`。
- **表达式口径直接当价格**：官方预设的 billing_expr 系数按「系数即真实单价」解析（p × 2.5 = $2.50/1M），不再做倍率换算；缓存读写未单列时按 new-api 默认口径（缓存读 = 输入价、缓存写 = 1.25×）。

## 升级提示

- 覆盖安装即可，模型来源顺序、计费价格源配置都会自动迁移，不需要手动处理。

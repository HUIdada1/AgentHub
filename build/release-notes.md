## 自定义供应商列表新增启用/停用开关与状态显示

- 供应商列表操作列尾部新增 40×22 胶囊开关：点击即时启用/停用，停用的供应商不再参与任何模型调用
- 停用态在名称旁显式标「已停用」并弱化整行文字 —— 此前"路由里没它"容易被误当成配置丢了
- 开关走独立通道，只改启用位、不碰 API Key 与地址（不会触发"改地址必须重填 Key"的防护把开关卡死）

## 供应商「编辑」弹窗重做：连接信息 + 模型列表，一个弹窗管到底

- 原先重复的「查看更多」与「编辑」两个弹窗合并为一个：Base URL / API 格式 / API Key / 备注 + 模型列表
- API 格式改为下拉（带端点路径），API Key 输入框带明文/掩码眼睛按钮，标题行显示「已保存 掩码」状态
- 模型列表每行＝模型 ID（含自定义显示名）+ 上下文窗口/视觉能力标签 + 连接测试 / 编辑 / 删除 图标按钮 + 启用开关
- 模型「编辑」走二级小弹窗：显示名 / 思考强度（含自定义预算）/ 用途标签 / 优先级 / 温度 / 最大 Tokens / 启用开关
- 模型列表头新增「全部启用 / 全部停用」，拉取一批模型后不必逐个点
- 删除模型改为先弹确认框（图标按钮误点成本高）

## 修复

- 清空标签不再被静默改回按模型名预填（前端标签输入框清空即真的清空）
- 供应商开关改为先翻转界面再落盘，并串行化：解决往返期间连点被吞与"点了没反应"
- 编辑模型保存会一并带上能力预判数据，模型行上的上下文/视觉标签不再莫名变化
- 思考强度切到「自定义」时落盘预算与界面显示的 4096 保持一致
- 删除网关详情里「真实调用一次」按钮：不带模型时必定失败，试调请用模型行上的按钮

## 新功能：号池共享配置纳入 WebDAV 同步

- 换第二台设备不再重配：模型权威目录（含倍率 / 能力 / 上下文长度）、映射类配置（别名 / 反向别名 / 自定义模型 / 渠道覆盖 / 回退链 / 禁用清单）、API Key 一起进入号池同步，登录同一 WebDAV 即自动带上
- API Key 跨设备沿用同一把密钥：客户端里已经填好的 Key 不用改，新设备同步后立即可用；只补本机没有的，不覆盖本机的启停状态
- 模型清单按渠道整体取新（新者胜），避免半新半旧的参数拼出矛盾条目；共享配置走独立文件，旧版本读不到也天然忽略，混版本运行互不干扰

## 记忆中枢：同步更准、更不卡

- 变更判定改为按内容比较（哈希 + 体积，不再掺 mtime）：跨设备时间戳天然不同，旧口径会把整棵树误判成「远端已改」而全部重写（实测一次重写 4744 个文件、冻结 139 秒），本地真有改动时还会被误报成冲突、阻断上传。现在只认内容
- 冲突裁决不再被下一轮同步撤销：选「保留本地 / 合并 / 另存一份」后，下次同步不会又把远端旧版覆盖回来（旧版会静默撤销裁决、丢数据）
- 大额变更落地改由工作线程批量写盘并让出事件循环：3000 个文件的同步场景，主进程冻结从 52.6 秒降到 144 毫秒，同步期间界面与记忆 API 不再卡死
- 落地前守卫补全：同步窗口内本地被改写（含本地新建的同名文件）一律升级为冲突交裁决，不静默覆盖

## 修复

- 记忆清单构建每次会在系统临时目录留下一个源码副本目录（长期使用可累积数百个），现已建完即清

## 说明

- 共享配置与号池归档共用同一套 AES-256-GCM + 密码派生密钥，但存在独立文件里，不改变归档与墓碑的读写
- 设备专属设置（监听端口 / 绑定地址 / 并发 / 限速 / 签到开关）刻意不参与同步，避免把另一台设备按自身环境调好的配置盖掉
- API Key 在加密包内以明文形式携带，受 WebDAV 密码保护，与账号凭据同一信任级别：共用密码即共用号池

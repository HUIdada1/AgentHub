## 修复
- 反代网关 · 小浣熊切号「跨号串号吊销」根治：小浣熊桌面端启动后会以本地设备标识（desktop-device-identity.json 中的 clientDeviceId）向服务端心跳绑定「设备与用户」，多账号切号共用同一设备 ID 会被服务端判定为跨号串号，返回 200003 校验失败并强制作废两端会话。现在每个账号入池时即派生专属的稳定设备指纹，切号时同步写入客户端标识文件——服务端把不同账号识别为不同电脑，彻底杜绝冲突吊销
- 反代网关 · 小浣熊切号「旧账号凭据反哺」：切号前若发现本机登录文件属于号池中的另一个账号，且官方客户端运行期间自动轮换刷新过 Token，先把最新凭据同步回该旧账号的号池记录，避免切走后号池持有的是已被轮换作废的旧 refresh_token、导致旧号失效
- 反代网关 · 小浣熊渲染层清理扩展：切号时除已有的 Cookies / Local Storage / Session Storage 外，一并清理移动端连接器缓存（mobile-relay 的旧账号长连接配对状态）与 IndexedDB，避免新 Token 混合旧连接会话触发服务端防串号拦截

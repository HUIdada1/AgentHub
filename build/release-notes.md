## 修复
- 记忆中枢 · 导入游标停摆根治：无 rowid 且以长文本为主键的源表（ZCode / Codex 会话库）此前只读首批若干行、单个文件条目数变少后游标永久卡死——现在正确按主键翻页、游标可回退，导入不再「卡在第一批」
- 记忆中枢 · 导入失败不再丢数据：整批落盘失败时游标仍被推进，这批数据被静默跳过且下轮不会重试——现在失败即中止本轮、游标原位保留，下轮自动重采
- 记忆中枢 · 同步「保留远端」修复：远端已删除该文件时，保留远端的裁决会写回一份空内容把本地覆盖——现在正确按「远端已删」处理，不再用空包覆盖
- 记忆中枢 · 导出不再污染运行配置：导出前抹除 API Key 时直接改到了配置缓存本体，运行中的 Key 引用被清空——现在在副本上操作，配置缓存不受影响
- 记忆中枢 · 深层项目归类修复：会话目录路径超过 8 段时反解放弃、项目一律归入 general（临时目录深达 9 段即可复现）——现在迭代加深 + 前缀剪枝，实测 26 段也能正确反解归类
- 记忆中枢 · 全量重建不再重烧模型：重建或外部编辑会把去重状态 / AI 已处理标记打回默认，全部条目重新消耗模型调用——现在原状态随条目继承，且仅内容 hash 变化才作废 AI 标记

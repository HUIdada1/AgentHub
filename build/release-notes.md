## 修复

- 修复中转 Trace / 部分模型一用就断的问题（#47）：入口处把 `developer` 角色统一映射为 `system`、legacy `function` 角色映射为 `tool` / `user`，收敛到所有渠道上游都接受的角色集——此前各渠道白名单互相冲突，同一条请求能否成功取决于当时命中哪个渠道，表现为时好时坏；映射后的大小写变体（如 `User`）也一并归一
- 修复 Qoder 每日 Credits 自动领取窗口错过的问题：每日 10:00（UTC+8）窗口重置前自动签到会被标成「今日已领」而永久错过当天 100 Credits，现在会自动推迟到窗口开放后补领（手动一键领取不受影响）
- Qoder 领取窗口的推迟只在当天内生效，且只认每日 Credits 类型的活动实例——其它活动的远期时间不会把自动签到带偏到几天后，也不影响其它渠道的正常每日签到

## 优化

- Qoder 签名会话池化：同一账号的签名会话跨请求复用，不再每个请求都实例化一次 wasm 上下文，请求延迟更低、内存更稳（token 轮换自动换新会话，上限 12 个按最久未用淘汰）

## 说明

- 既有渠道（Trae / WorkBuddy / 小浣熊 / ZCode）行为与配置不受影响

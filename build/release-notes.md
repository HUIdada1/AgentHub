## 新功能：渠道成本感知路由（渠道降级）

- 号池新增「成本档位」标注：免费 / 低成本 / 普通。ModelScope（魔搭）默认免费、LobsterAI 默认低成本，其余渠道默认普通，均可在号池页渠道卡顶部随时调整
- 「配置 → 反代网关 → 请求与路由」新增「渠道优先顺序」：选「免费 / 低成本优先」后，免费渠道的额度优先消耗，不可用（号池耗尽/降级冷却）时请求自动落付费渠道，恢复后自动回切——全程零感知，不白撞限流
- 每个 API Key 可单独覆盖全局的渠道优先顺序：生成 / 编辑 Key 弹窗新增「渠道策略」（跟随全局 / 智能打分 / 免费优先），Key 列表对显式覆盖显示标签
- 修复：含无限额度（企业版）账号的渠道在智能路由打分中垫底的问题——免费优先模式下这类渠道按超大余额参与排序，不再排在付费渠道后面

## 说明

- 默认「智能打分」与旧版本行为完全一致，只有开启「免费优先」（全局或某个 Key）后才按成本档排序
- 渠道失败熔断、账号冷却、模型级负缓存等既有机制不变；成本档只决定「可用时谁排前面」
- 免费额度每日限量（魔搭魔粒靠每日任务领取），免费渠道耗尽后自动落付费属正常现象，第二天额度刷新自动恢复优先

## 记忆中枢

- **全量索引重建不再冻结应用**：重建挪进独立工作线程（先建旁路库、单事务换入），重建期间界面、记忆中枢本地 API 与 9527 模型网关照常服务，不再整体卡死 33~58 秒；worker 异常时自动退回主进程同步重建，功能不丢。
- **重建大幅提速**：去掉逐文件小事务（合并为单一大事务）、重建期间摘除 FTS 插入触发器末尾统一重灌、跳过空转删除与必然为空的回库查询，实测 4751 个文件由 44 秒降至约 6 秒。
- **重建安全性加固**：worker 引导采用与记忆打包同款的临时目录方案（不依赖 asar 在工作线程内的加载行为，开发态与安装版行为一致）；重建期间写入队列照常串行，置顶/星标/AI 处理状态等按快照完整继承。
- 重建完成后自动清理旁路库与临时文件；主库占用时 checkpoint 自动重试，拿到陈旧快照也有 watcher 自愈兜底。

## 反代网关（Trae 渠道）

- **修复官方回调被误拦截**：官方登录页不回传自定义 state、只带 refreshToken/userInfo/userJwt 等凭据，旧校验会把它当外来请求拒掉导致登录卡住；现对齐参考项目口径——state 一致性仍严格校验，凭据齐全即放行，login_trace_id 不一致改为告警留痕不再阻断。
- **授权码换令牌更稳**：同时尝试 `/trae/api/v3/oauth/ExchangeToken` 与 `/cloudide/api/v3/trae/oauth/ExchangeToken` 双端点路径，错误信息对齐官方 ResponseMetadata 格式，换令牌失败时能看到真实原因。
- **回调凭据键补全**：userJwt / user_jwt / UserJwt / userInfo / user_info 形态的回调参数现在都能被识别与解析。

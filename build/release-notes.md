## 新功能
- 反代网关 · 模型输入模态自动识别（五渠道）：多模态模型不再被误报成纯文本——此前 glm-5.3-flash 等实际支持附图的模型在模型目录里被标成纯文本，下游客户端直接拒绝附图。现在 ZCode 渠道优先读官方客户端自带的能力表，WorkBuddy / 小浣熊 / Trae 官方字段优先、通用嗅探兜底，多渠道共享模型名按「任一渠道支持即支持」合并
- 反代网关 · 模型上下文 / 输出上限改由官方客户端元数据解析：GLM-5.3-Flash 上下文 1M / 输出 128K 等真实上限进入模型目录与合并视图；WorkBuddy 等不传 max_tokens 的客户端不再被写死的 8192 截断（长回答「达到最大 token 限制」问题根治）

## 修复
- 反代网关 · ZCode 渠道 start-plan 出线 405/3012「unusual activity」根治：上游对 system 做官方客户端检测（真文本前缀匹配），此前第三方请求一律被拦、账号还被误判凭证失效——现在注入官方提示词前缀（优先从本机客户端 bundle 提取、内置常量兜底），渠道恢复可用
- 反代网关 · ZCode 渠道用量统计修复：prompt_tokens 恒为 0（真实 usage 只在 message_delta 事件里）；缓存命中 token 全链路记录，请求明细新增「缓存命中」列（悬停显示缓存读/写明细）
- 反代网关 · 429 冷却统一为绝对时刻：Retry-After 的剩余时长此前被误当墙钟时刻，2 小时冷却实际只冷却 1 秒——现在正确换算对齐，限流恢复期不再空转重试
- 反代网关 · 首字节超时按 prompt 规模放大且不再误罚账号：超长 prompt（如 54 万 token）的 prefill 顶穿固定 30 秒被误判账号故障、连续熔断 30 分钟——现在基准 30 秒 + 每万 token 追加 1 秒（封顶 180 秒），且首字节超时只换号不冷却、不计入熔断
- 反代网关 · 冷却到期读时即派生回在线：号池列表的冷却状态到期立即恢复显示，并顺带清掉过期的「最近错误」气泡（完整历史仍保留在请求明细）
- 记忆中枢 · 同步拉包失败不再覆盖远端：网络异常曾被当成「远端没有包」直接整包上传，把其他设备已同步的改动覆盖掉（不可逆）——现在异常一律中止本轮，只有真 404 才走首次上传
- 记忆中枢 · 其余修复一批：写入摘要同样走脱敏（隐私规则不再被摘要旁路）、编辑记忆不再抹掉 cwd/git 溯源、全量重建不再丢置顶/星标等用户状态、回收站还原禁止覆盖索引库等内部文件、模型条目缺 tags 不再导致 AI 任务全灭等
- 安装器 · 更新/卸载前的解锁等待改为按时间探测：不再固定盲等约 5 秒（每次装机省 4~5 秒），慢机器上锁未放开时也会等到位再继续，杜绝「Failed to uninstall old application files.: 2」复发

## 新功能

- 反代网关：号池中小浣熊账号签到时自动领取首次登录奖励（电脑端与手机端各一条，一次性新手福利）——台账未结算才探测，领取成功（含此前已发放的幂等情形）即打上标记后续不再重复领取；领取失败下轮签到自动重试，直到领取成功；手动签到、OAuth 登录后与定时自动签到共用同一链路，签到记录里可直接看到「首登奖励领取 2 项」摘要
- 反代网关：顶部「生态接入」右侧新增「日志」页签——网关各项操作一条一条落库（代理请求 / 签到 / 账号 / Key / 配置 / OAuth 登录 / 模型目录 / 切号 / 生态接入 / 号池同步 / 冷却与风控），本地存储 30 天，支持时间段、等级（信息 / 警告 / 错误）与操作类型筛选，分页浏览，一键导出 Excel（.xlsx）

## 说明

- 代理请求每条按结果记等级：成功=信息、需人工过码 / 4xx=警告、失败 / 5xx / 网络异常=错误；日志写入永不反噬业务动作
- 操作日志与现有用量流水同库同量级，30 天 + 5 万行上限自动清理，无额外配置

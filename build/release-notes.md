## 新功能
- 记忆中枢 · 自动化页「立即执行」排队化：点「立即执行」即入队返回（忙时自动排队，可连点多个任务，不必等一个跑完），进度弹窗跟随后端运行快照（排队中 / 执行中），跑完从执行时间线取本次结果展示；正跟踪别的任务时再点只入队并提示，不抢走弹窗；任务卡显示「已排队」徽标，超预算前置拒绝不入队
- 记忆中枢 · 自动化页任务卡新增「编辑」节奏弹窗：三种节奏（每隔固定分钟 / 每天固定时间 / 每周固定日 + 时间）任选其一，保存时把不用的模式置空，后端按非空项生效；顺手修复节奏编辑把 weekly 置空后 `=== undefined` 误判为有效值产生非法日期的问题

## 修复
- 记忆中枢 · 项目归档「更多操作」⋯ 按钮点击失效根治：v1.38.1 全站 title→el-tooltip 机械替换把 el-dropdown 的触发器包坏了（EP 的 dropdown 内部本就用 tooltip 机制管触发器，再嵌一层 tooltip 后点击的展开切换失效，弹层渲染了却不显示）。现已去掉两处 dropdown 内嵌的 tooltip，提示改用原生 title，项目归档与记忆浏览的行内菜单恢复弹出
- 记忆中枢 · 「索引与记忆文件不一致」点「一键修复」整窗卡死十几秒根治（三层）：
  - SQLite `recursive_triggers` 默认 OFF 时 `INSERT OR REPLACE` 引发的隐式 DELETE 不触发 FTS 清理触发器，FTS 与内容表行数逐渐漂移，每次修复末尾自检都检出不一致并触发十几秒的全表 FTS 重建——这才是卡死的大头。现已开启 `recursive_triggers = ON` 根治，存量漂移经几轮修复逐轮收敛
  - 重建循环改为按小批（20 个文件 / 批）让出事件循环：重算跑在 Electron 主进程，一口气同步重算全部文件会阻塞渲染进程的全部 IPC（低配电脑上表现为整窗冻结）。宁可整体慢一点，界面保持可响应
  - 修复返回值直接带诊断快照，前端不再重复发第二次全量诊断
- 记忆中枢 · L2 蒸馏术语表三处改进：术语表标题带项目短名（多份同标题「术语表」分得清归属）；术语按文件路径归属项目（frontmatter 缺 project 字段的系统产出不再落成「通用」）；通用表已有的同名术语不再进各项目的术语表（跨文件去重）

## 说明
- 「一键修复」期间界面仍有批间小幅等待（每批 20 个文件的 SQLite 同步重算本质），属正常现象；首次修复会收敛历史漂移，耗时略长，之后恢复正常

## 反代网关（五项修复 + 一项体验优化）

- **修「上游 200 但无可用内容被当成功」**：ZCode / Trae 账号余额耗尽时上游返回 HTTP 200 但没有任何可用内容，此前被记为 200 成功（0 token），账号不冷却、失败计数不涨，号池一直死磕同一个号。现在「零事件」与「有事件但无可用内容」两种形态都按 502 空流判定，连续 3 次自动熔断换号；额度耗尽（402）与上游明确报错的事件不受影响，不会被误降级罚号。
- **修小浣熊每日积分「显示已领取但余额不变」**：每日 300 积分是懒结算——服务端要等当天首次 Web 会话活动才真正落账。签到前先请求一次 setting_info 激活当日会话再领取，不再出现打开官方客户端后积分才补上的情况。
- **修 Qoder 模型「列表里有、调起来报不可用」（code 11102）**：静态兜底模型表此前两个产品（CN/国际版）共用一张表，没拉取过目录的一侧会凭空宣称拥有对方的模型，请求被路由过去必然失败。现在兜底表按产品隔离，拉取过目录的产品只认目录内容；失败轨迹同时改为「渠道名(实际用过的账号)」并区分「降级中 / 无可用账号」，账号名一律脱敏（邮箱保留前两位 + 域名），不再原样外泄。
- **记忆同步唤醒卡顿修复**：休眠唤醒后的自动同步里，本地清单构建（数千文件逐个读盘算哈希）此前在主进程同步执行，界面和 9527 网关会一起卡住一会儿。已挪入 worker 线程执行（含 5 分钟超时护栏与临时文件清理），主进程不再被整段占住。
- **项目归档元数据补全与自愈**：显式指定项目名写入的记忆此前不探测 Git，项目卡永久缺「远程仓库 / 本地路径」。现在带工作目录写入会一并补全；启动后异步自愈从历史记忆里回收 cwd/git 补回台账（逐项目限量读取，不阻塞启动），并自动剔除家目录、盘符根等误记的无效路径；项目卡新增「关联本地仓库」菜单，可手动补全。

## 记忆中枢（界面优化）

- **Agent 卡片统一排序**：「Agent 接入」页、手动接入下拉、「仪表盘·Agent 连接状态」三处共用同一套口径——已接入的排前面，其余保持默认序，「通用（~/.agents）」扩展位固定垫底。
- **接入页头部收敛**：删去整页说明块，本地服务运行状态、已连通统计与路径预检收进「本地 MCP 服务状态」卡片标题行，页面更紧凑。

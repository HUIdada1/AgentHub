## 新功能

- 反代网关：新增「上游启闭」渠道级开关——侧栏反代网关卡片右侧与「配置 · 反代网关」页头各一个入口，弹窗内列出全部渠道（图标 + 名称 + 启用开关 + 小问号操作说明）；关闭某渠道后，反代网关的全部页面（总览 / 号池 / 模型 / Keys / 统计 / 号池同步等）立即动态隐藏该渠道的卡片与信息，下拉选择器等操作入口同步收起，路由与调用、自动签到、额度刷新、本机探测也不再使用它；重新打开立即恢复显示与调用
- 侧栏反代网关卡片：「上游」计数改为「已启用上游 N 个」，与渠道启闭联动（关闭几个渠道立即少几个）

## 改进

- 侧栏左上角记忆中枢卡片第二行改为「普通记忆 N 条 / 深层记忆 N 条」，与右上角「N 个 Agent 已连通」不再重复展示
- 侧栏四张模块卡片的数字全面加单位：机器 N 台、已收纳 / 待裁决 / 接入工具 N 个、Key N 个、记忆 N 条；反代网关端口号去掉前面的冒号

## 说明

- 渠道启闭状态保存在框架整体配置的 proxy.channelEnabled（缺省 = 启用），只落显式关闭的渠道
- 关闭的渠道在 /v1/models 对外模型列表中同步隐藏（该渠道独有的模型不再暴露给下游客户端），网关探活（/healthz）只看启用渠道

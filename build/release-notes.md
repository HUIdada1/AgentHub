# v1.89.0 更新说明

## 修复：更新安装「应用退了、新版本没装上」的死结

- **问题**：1.86 以来的历次热更新中反复出现「点击更新后应用退出，但新版本没有装上」，且无任何报错可查。1.88.x 真机取证（系统事件日志 + 主进程注入实验）定位到根因：安装器启动时检测到应用仍在运行，会尝试关闭它——Electron 多进程应用完全退出需要一到两秒，慢于安装器的进程轮询，安装器判定「应用无法关闭」后在静默模式下直接放弃：不安装、无界面、无日志，只留下已退出的旧应用和没装上的新版本。
- **修复**：安装器的启动时机整体后移——从「应用还在运行时」移到「应用完全退出的最后一刻」。此刻系统进程表里已经没有 AgentHub，安装器不再需要关闭任何进程，启动即安装，装完自动启动新版本。此前几版的重试/校验/副本预热等加固全部保留。
- **新增安装哨兵**：安装器启动后应用即退出，安装成败由下次启动判定并记入 `logs/crash.log`，任何环节的失败都不再无据可查。

# v1.88.1 更新说明

## 修复：更新安装确认机制——不再「启动了就算成功」

- **问题**：1.87.2 起点击「立即重启安装」后偶发应用退出、但新版本没装上的现象（1.88.0 真机取证：两次点击安装器均无果，且无崩溃记录、无杀软拦截记录）。根因是安装器启动后应用只等 200 毫秒就认定「已启动」随即退出——安装器进程是否真的完成安装，应用端全程无感知，一旦安装器在窗口期内意外死亡（扫描挂起、早期退出等），既装不上也无从取证。
- **修复**：安装器启动改为**等待其真实退出并核对退出码**——退出码为 0（安装器报告完成）应用才退出；非 0 记入日志并重试，仍失败回退提权方式，全程在更新中心给出明确原因。安装器长时间未退出（慢盘、静默卸载旧版等）超过 120 秒按「仍在运行」放行退出，不影响其后台继续安装。
- 安装器正常 6~10 秒完成，此修复仅让应用多陪它几秒再退；下载、校验、副本预热、失败重试等 1.87.x 既有保障全部不变。

# v1.87.2 更新说明

## 更新链路再加固：安装包「搬台面」

- 在 1.87.1 自管安装器启动的基础上再加一道保险：**下载完成立即把安装包复制到系统临时目录（`%TEMP%\AgentHub-update`）的副本，安装时优先从副本启动**。
- 背景：安全软件对「刚从网络下载的未签名安装包」所在的更新缓存目录盯得最紧，安装包刚落盘就被扫描锁定时，安装器启动会撞上文件占用错误。提前复制一份到临时目录，既是完整读盘预热（扫描锁就地解开），也把启动落点换出了缓存目录，命中锁定的概率大幅降低。
- 副本复制完成后同样做整包 sha512 校验，复制中断的文件绝不会被拿去安装；副本失败时自动回退原路径，不影响更新可用性。
- 1.87.1 的既有保障不变：启动前校验、失败自动重试、提权回退、失败不退出应用并在更新中心给出明确原因，更新组件内部日志全程记录到 `logs/crash.log`。

# v1.87.1 更新说明

## 修复：更新安装「应用退出后新版本没装上、也没自动重启」

- **问题**：点击「立即重启安装」或退出时自动安装后，应用退出、但新版本没有装上、也没有自动重启，且没有任何报错。根因是安装器启动此前交给 electron-updater 的内部实现——它发出启动指令后立即退出应用，一旦安装器启动失败（杀毒软件对刚下载安装包的实时扫描锁、文件占用等），错误信息随应用进程一起丢失，无从排查。
- **修复**：安装器启动改为自己接管——启动前先整包校验 sha512 并读盘预热（化解杀软扫描锁）；启动失败自动重试（1.5 秒间隔最多 3 次），仍失败回退提权方式拉起；任何一步失败应用**都不再退出**，更新中心会显示明确原因，可直接重试。更新组件的内部日志也会记入 `logs/crash.log`，后续更新问题可精确定位。

# v1.87.0 更新说明

本版新增第五大板块「提示词库」：一个本机优先、可跨设备同步的提示词资产库，外加一个对标「增强提示词」的优化工作台。同时带来外置插件的桥接与内嵌界面、以及无边框自绘标题栏。

## 提示词库（第五大板块）

- **优化提示词**：上方输入原文、中间按钮、下方出结果。可选优化风格（内置 5 套：通用增强 / 更简洁 / 更结构化 / 补全约束 / 面向编码任务）、选模型，并可调长度上限、温度、最大输出、超时与目标场景；结果可一键复制、重新优化、保存到库、与原文并排对比。
- **个人提示词库**：两级分类与标签、全文搜索、收藏、卡片/列表视图、批量操作与回收站；每条都有版本历史与血缘（记录从哪条原文、哪个风格、哪个模型生成）。
- **优化历史**：最近 50 次记录（失败的也留痕并写明原因），可回填、复制、删除。
- **复用平台模型**：优化直接走「设置 · 模型与网关」里已配置的供应商与模型池，沿用降级链、失败重试与用量记账，不需要额外配置。

## 跨设备同步（独立链路）

- 与技能仓库 / 用量统计 / 号池管家 / 记忆中枢**各自独立**、互不阻塞，在「设置 · WebDAV 同步」里有自己的根目录。
- **冲突默认自动合并**（默认新者优先），被放弃的那一份会写入该条目的版本历史，可在同步页逐条查看并改判；也支持一键「自动合并全部」，或改为全部人工裁决。
- 同步周期在「设置 · 同步时间 → 提示词库」按小时设置，默认每 4 小时，默认开启。
- 回收站删除以墓碑方式同步，不会在别的设备上「复活」；远端清单异常为空时会停下来而不是覆盖。

## 外置插件与窗口

- 插件可声明桥接资源与内嵌界面地址，界面直接嵌入主区域（CSP 仅放行本机回环地址）。
- 无边框窗口 + 自绘标题栏：版本 / 作者 / Star / 主题 / 设置，以及最小化 / 全屏 / 关闭。

## 升级提示

- 覆盖安装即可。本版不改动既有四大板块的数据与配置；提示词库默认库目录为 `~/AgentHub/prompts`，首次使用会自动创建，本机偏好（优化风格与历史）另存于用户数据目录，不参与同步。

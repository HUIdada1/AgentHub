## 认证
- JWT(HS256)，payload 含 `exp/iss/jti/name/nation_code/nbf/owner_type/sid`
- access_token 约 3h，refresh_token 约 30 天；刷新窗口 300s

- 登录：`/code/authorize` → 深链 `office-raccoon://auth/callback?code=` → `POST /api/web/auth/v1/login_with_authorization_code`
- 请求头：`Authorization: Bearer <access_token>`，团队版加 `X-Org-Code: <office_identity>`

## 受信设备（防伪核心）
- `POST /api/web/auth/v1/devices_current_bind`：body 含 client_device_id/client_platform/client_version/device_name/os/os_version/application="desktop"/push_permission；返回服务端 device_id
- `POST /api/web/auth/v1/devices_current_heartbeat`：默认 60s 心跳
- 请求头：`X-Client-Platform`/`X-Client-Device-ID`/`X-Client-Version`/`X-Request-Id`(UUID) + Authorization
- 绑定失败会自动 refresh 后重试一次（bindWithOneRefresh）

## LLM 接口
- `POST /api/web/llm/v2/chat/completions`（OpenAI 兼容，SSE 流式，模型 `raccoon-chat-ml-5-5`）
- 图片：`POST /api/web/llm/v2/images/gen`
- box-agent 用官方 OpenAI SDK，extra_body 双层嵌套，含 `include_usage`、token usage 在 finish 事件
- 支持 SenseNova 私有方言（XML 伪 tool_calls 恢复、reasoning_split）

## 积分/余额
- `GET /api/web/points/v1/balance` → `{"code":0,"data":<余额>}`
- `GET /api/web/points/v1/bills?paging.limit=N&paging.offset=M`（或 cursor 分页）→ 明细
- 登录送积分：`POST /api/web/desktop/v1/login/points/grant`
- 账户配额字段：daily_question_count/limit、monthly_web_search_count/limit、used_space_mb 等

## 遥测
- `POST /api/web/b/v1/m`（个人）/ `/api/web/org/b/v1/m`（团队）
- body `common_header:{client_agent, machine_id}` + metrics 事件
- 【会话2已修正】`machine_id` 是**全局硬编码常量** `simulator-f31d2afc...`，所有客户端相同，**不构成设备区分**；渲染层**没有** fingerprintjs 实质指纹采集（"fingerprint" 命中全是编辑器语法高亮和 FNV 文本 hash）。

## 防伪强度结论
中低。无代码混淆、无请求签名/HMAC、无证书 pinning、无反调试。防伪 = JWT + x-client-device-id + 受信设备绑定。

## 会话2 已修正/补充的关键点（合并时以会话2 文档为准）
1. `x-client-platform` 两条链路格式不同：box-agent 链路 `desktop-windows-x64`（带架构），受信设备头 `X-Client-Platform: desktop-windows`（不带架构）。
2. box-agent `x-client-version` 经 semver 校验并 `removeprefix('v')`，实际发 `1.0.35`（不带 v）。
3. 新增 4 个会话关联头：`X-RACCOON-Session-ID` / `X-RACCOON-Turn-ID` / `X-RACCOON-Title` / `X-RACCOON-Call-Kind`（llm/base.pyc `_agent_headers`），反代需决定复刻或置空。
4. 心跳无 body、间隔 60s；绑定失败 401 时 refresh 后重试一次；唯一设备类错误码 `device_session_mismatch`。
5. 号池反关联暴露面仅 4 项：出口 IP、x-client-device-id、心跳时序、X-Request-Id 时钟。
